- Codex App Server 与 Windows desktop DSH ACP 的受控新会话 Adapter，持久化会话/任务映射、取消、默认拒绝、UNKNOWN 不重放、关闭与锁保留语义。
- #51 有效原请求遇到过期回执时重新封装旧业务结果；#56 会话业务结果已落盘、inbox 收据尚未落盘的写入前缀也遵循相同规则。不会重新执行原生操作。
- #55 新注册发现和新业务接纳有界地检查本地 Adapter 活性；原先已经接受的幂等重试和关闭/取消仍可按原所有权处理。
- #59 Windows native 固定响应验收要求显式 PowerShell 7 路径/哈希，在隔离 home 检查版本，仅追加该目录至允许列表。正控使用同一程序，权限四要素和 sandbox 方言不放宽。

Gateway CLI 没有默认开启真实 Adapter；嵌入者仍须显式配置工厂/导出 Agent、隔离目录、工作区和 loopback fixture。所有者、版本/程序哈希和原生权限仍是边界。本候选没有生产模型入口、GUI attach 或 Agent 自批准。
